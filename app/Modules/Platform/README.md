# Platform module

The shared kernel: audit log, settings, outbox, localisation helpers, storefront cache, branding and the admin shell. Every module may use it; it uses no other module (see `tests/Architecture`).

* Phase 10, slice 4a: `/admin/settings` (business profile, tax switches, read-only currency and language), `/admin/features` (a registry in `Support/FeatureFlags`; `features.manage`), `/admin/maintenance` (`Actions/MaintenanceSwitch`; `settings.manage` plus the staff member's own password through `Contracts/StaffReauthentication`, implemented by IdentityAccess) and `/admin/audit` (`audit.view`; `Services/AuditLogQuery`, filters, masked addresses, capped CSV export). `Support/SettingsWriter` saves a group as one audited, versioned, locked step; `Support/BusinessProfile` feeds `<x-platform::business-block />` on receipts and packing slips. Set `APP_MAINTENANCE_DRIVER=cache` in production when there are several servers.
* Phase 10, slice 4b: `/admin/ops` — health (`Services/SystemHealth`, `Support/HealthProbes`, shared with `/readyz`), scheduler (`Listeners/RecordScheduledTask` keeps `scheduled_task_runs`), failed jobs (`Services/FailedJobs`, `Actions/RetryFailedJob` only for `config/ops.php` `retryable_jobs`, `ForgetFailedJob`; `queues.view` / `queues.manage`) and data checks (`Contracts/IntegrityCheck`, `Support/IntegrityRegistry`, `Actions/RunIntegrityChecks`, nightly `Jobs/RunIntegrityChecksJob`; results in `integrity_check_runs`). A module adds a check by registering it in its service provider; checks only read.
* Phase 10, slice 4c: `Support/IntegrationCatalogue` lists the editable provider fields; `IntegrationCredentials` gives the value in force (saved here, else the server's) and applies saved mail settings when Laravel builds its mail manager; `Actions/SaveIntegration` and `IntegrationWriter` validate, ask for the staff member's password, lock, version-check and audit (secrets only as "changed"/"removed"); modules register connection tests (`Contracts/IntegrationTest`) with `IntegrationTests`; `HostGuard` keeps the mail test away from local and private addresses. Platform uses no other module.
* Phase 10, slice 5a: `Contracts/DashboardTile` + `DashboardRegistry`, `Contracts/SearchProvider` + `SearchProviders` and `SavedFilterScreens` are filled by the modules' own providers (Platform reads none of their tables); `SavedFilters` keeps a person's own filters per list (`saved_filters`); `/admin` (tiles), `/admin/search` and `/admin/saved-filters`.
* Phase 10, slice 5b: `Contracts/BulkAction` + `Support/BulkActions` (filled by the modules' providers), `Actions/RunBulkAction` (at most 50 rows, each row through the module's own Action, one `bulk.run` audit record), `Http/Controllers/Admin/BulkController` (confirm, run, result) and the `<x-platform::bulk-bar>` component. Platform reads no module's tables.
