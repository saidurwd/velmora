## Rules enforced in code

- A staff member can only grant roles/permissions they hold themselves; only a Super Admin can assign Super Admin.
- The last active Super Admin cannot be demoted, disabled or have the role removed.
- Super Admin's permissions cannot be edited; system roles cannot be deleted; roles still assigned cannot be deleted.
- Unknown permission names fail closed (access denied / ignored when saving a role).
- Every `/admin` route requires `auth:admin` + `permission:*` unless listed in `tests/Architecture/RouteAuthorizationTest.php`.
